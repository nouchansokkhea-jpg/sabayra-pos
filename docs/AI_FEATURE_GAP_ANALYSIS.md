# SABAYRA AI Center — Feature Gap Analysis

| Feature Domain | Existing Capability | Identified Gap | Planned Implementation |
| --- | --- | --- | --- |
| **AI Center Navigation & Overview** | 4 standalone Business Intelligence links (`/app/ai/insights`, `menu-audit`, `sentiment`, `upsell-pairings`); `AiMenuBuilderController` isolated under Catalog | No unified **✨ AI Center** hub, no credit/usage KPIs, no overview of inventory warnings & insights | Unified `✨ AI Center` navigation group + **AI Overview** hub (`AiCenterController@overview`) integrating real usage, remaining credits, inventory risks, and actionable next steps |
| **AI Provider Layer** | None (no LLM HTTP client or provider abstraction) | Tightly coupled heuristics only; no configurable OpenAI/Gemini selection, no retry/timeout/fallback | `AIProviderInterface`, `AIManager`, `GeminiProvider`, `OpenAIProvider`, `AIResponseService`, `AIContextService`, `AIUsageService` with graceful degradation |
| **AI Business Assistant** | None | No chat UI, no Khmer/English/mixed Q&A, no tool-calling loop, no conversation persistence | Chat UI + AJAX endpoint, conversation history (`ai_conversations`, `ai_messages`), 7 verified read-only analytical tools, Khmer/English/mixed responses, copy/clear/new actions |
| **AI Menu Creator** | Static hardcoded sample array in `menu-builder.blade.php`; `store()` writes items | Cannot generate descriptions from product/ingredients, cannot improve existing copy, cannot translate Khmer↔English, cannot save drafts without overwriting products immediately | Live AI Menu Creator supporting Generate, Improve, Translate to Khmer/English, Short & Promotional copy, edit-before-apply to existing `Product`, and saved history (`ai_generated_contents`) |
| **AI Marketing Studio** | Manual `coupons`, `happy_hours`, `referrals` CRUD only | No AI copy generator for Facebook, TikTok scripts, Telegram blasts, or seasonal promos | Dedicated Marketing Studio targeting Facebook, TikTok, Telegram & General with campaign/tone/language controls, regenerate/edit/copy/save workflows |
| **AI Inventory Forecast** | Static threshold check (`current_stock <= low_stock_threshold`), `RecipeDeductionService` logs `inventory_movements` | No consumption velocity math, no days-remaining projection, no reorder quantity calculation, no overstock/slow-moving analysis | Statistical depletion engine combining product sales (`order_items`) + recipe BOM (`recipes`/`recipe_items`) + `inventory_movements` + `purchase_orders`, paired with LLM operational explanation & `ai_forecasts` storage |
| **AI Sales Prediction** | Historical KPIs and 14-day line chart in `ReportController` | No `1d` / `7d` / `30d` revenue/volume forecast, no day-of-week seasonality, no confidence intervals, no insufficient-data guard | Statistical predictor (weighted moving average + exponential smoothing + day-of-week index + min-history threshold guard `"Not enough historical data to generate a reliable forecast yet."`) + AI narrative explanation |
| **AI Business Insights** | On-the-fly `AiInsightsService::generateWeeklySummary()`; unused `business_ai_insights` table | Insights not persisted, cannot be marked reviewed or dismissed, `AiInsightsService` lacks explicit `where('business_id', ...)` guard | Persist verified insights in upgraded `business_ai_insights`, add review/dismiss actions, surface on AI Overview & Business Dashboard |
| **Subscription & Credits** | `Plan` & `Subscription` tables exist with `SUBSCRIPTION_PLANS_ENABLED` flag | No AI credit allowances, no per-feature entitlement flags, no atomic usage logging or failure refund ledger | Add AI columns to `plans`, add `ai_credit_ledgers` + `ai_usage_logs` with `request_uuid` idempotency, credit refund on provider error, Super Admin plan & platform AI controls |
| **Security & Privacy** | `BelongsToTenant`, Spatie permissions, `SecurityLog`, `PlatformSetting` encryption | Need PII minimization in AI context payloads, strict role/feature enforcement, prompt-injection & arbitrary SQL prevention | Enforce `business_id` from server `TenantContext`, strict allowlisted tools, PII redaction, encrypted API keys, route throttling, and automated security tests |
